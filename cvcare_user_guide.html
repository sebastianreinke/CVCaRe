CVCaRe

A practical guide to loading, inspecting, analysing, and exporting capacitive cyclic voltammograms.

Contents: OverviewUsing the GUIMethodsNotesAcknowledgement

Overview

CVCaRe reads cyclic-voltammetry files, selects complete cycles or individual half-cycles, plots the selected data, estimates capacitance from several scan rates, and performs CaRe resistance/capacitance/distortion analysis on complete CVs.

Data input

Handles tab-, semicolon-, and whitespace-separated exports, decimal commas or points, unit prefixes, explicit cycle columns, and voltage-trace cycle detection.

Inspection

Provides live active-CV visibility, an isolate selector, filtering, model overlays, synthetic HalfCV branches, and integration shading.

Analysis

Supports current-vs-scan-rate capacitance fitting, analytical CaRe, optimisation-enhanced CaRe, directional integration, and a virtual-full-CV HalfCV path.

Export

Exports standardized CV tables, side-by-side datasets, split cycles, capacitance results, and reconstructed CaRe model curves.

Using the GUI

Load CV files

  1. Choose Full cycles, Anodic (forward), or Cathodic (backward) in the sidebar.
  2. Use ... to select one or more files.
  3. For each row, specify the cycle number, scan rate in mV/s, and optional evaluation voltage in V.
  4. Click Load.

Inspect curves

Uncheck active to hide a CV immediately and exclude it from later aggregate fits. The corresponding CaRe fit, mirrored branch, and integration shading follow the same visibility rule. Use Isolate to show one CV without changing which datasets are active for fitting.

Capacitance

Load at least two active CVs with valid scan rates, choose a method and segment, then click Compute capacitance. The tab rereads scan rates, evaluation voltages, active flags, and filter choices from the sidebar before calculating. Its diagnostic pop-up shows the measured scan-rate/current points and fitted line.

CaRe

Load a full CV, enter its scan rate, select its CV number in the CaRe tab, choose the method, and click Compute for selected CV. Results are resistance, capacitance, and distortion parameter; the model curve is shown as a dashed overlay.

HalfCV

For an anodic or cathodic half-cycle, Show mirrored branch displays a dash-dot synthetic opposite branch. Compute CaRe on virtual full CV evaluates the resulting virtual closed loop. This is model-based: the result contains information only from the selected measured half-cycle.

Directional integral

In the Integral tab, type lower and upper bounds directly, choose direction, then compute. The plain-text bounds accept . or , decimal separators. The corresponding curve-to-zero area is shaded in the main plot.

Key Background Methods

Cycle and half-cycle detection

When a source file has no cycle-number column, CVCaRe determines the initial potential direction and searches for local voltage maxima and minima. Immediate-neighbour comparisons allow equal values so digitised plateaus at a turning point are not missed; a stricter wider look-ahead test avoids registering minor noise as a peak. Consecutive plateau points are collapsed into one representative turning point before slicing branches.

Current versus scan-rate fitting

For active CVs, CVCaRe fits the selected current quantity against scan rate, either with an intercept or forced through the origin:

I = Cν + b    or    I = Cν

The fitted slope is capacitance. Full-CV MinMax uses half the peak-to-peak current difference; anodic/cathodic choices use directional current; the selected-voltage method uses current at the requested potential.

Analytical CaRe

CaRe calculates a fill factor from the branch-to-branch current-difference area, normalised by the potential-window/current-range rectangle:

fill factor = enclosed CV area / (potential window × current range)

It numerically obtains the RC distortion parameter that matches the measured fill factor, derives a vertical-current correction ratio, corrects the capacitance estimate, and estimates resistance from the distortion parameter, scan rate, capacitance, and potential window.

Optimisation-enhanced CaRe

This method uses the analytical result as an initial estimate. It separates forward and reverse branches, reconstructs time from voltage and nominal scan rate, and minimizes the combined root-mean-square difference between measured branch currents and the exponential R-C response to a triangular voltage waveform. It optimizes resistance, capacitance, and a vertical current offset.

Interfacial scan rate

The core method FullCV.true_interfacial_scanrate(resistance) calculates the interfacial potential point-by-point from an assumed resistance:

Uinterface = Uapplied − I R

It reconstructs elapsed time from nominal scan rate and potential increments, then returns the local derivative:

νinterface = ΔUinterface / Δt

This returns a trace rather than one average scan-rate value and is currently available in the core model rather than as a dedicated GUI panel.

Notes and Limitations

  • Visually inspect automatically detected cycles for incomplete, unusual, or noisy waveforms.
  • Savitzky–Golay filtering can improve inspection but may change results for methods that use the stored filter flag.
  • CaRe needs a defined scan rate and is intended for capacitive full CVs.
  • The HalfCV workflow is a synthetic extension, not an independent two-branch experiment.
  • Compare the overlay of the recalculated R-C-CV with your data to judge whether the model is appropriate for your system.
For plain comma-separated files with dot decimals, enable Force standard CSV format. For typical potentiostat exports, leave it disabled so the reader can detect the format automatically.
